**Bugs in the code (fixed in the code):**
- **Pagination** (`Pagination.java`): page numbers were treated as starting at 0, but the spec says they start at 1. Page 1 was returning items 11–20. The start index is now `(page - 1) * pageSize`.

- **Shipping** (`Shipping.java`): free standard shipping used `> 200.00`, but the spec says 200.00 or more qualifies. Changed to `>=`.
- **Coupons** (`Coupons.java`, `ErrorCode.java`): expired coupons were never rejected. I added the `COUPON_EXPIRED` error code and a check using `today.isAfter(expiresOn)`, so a coupon still works on its expiration date.
